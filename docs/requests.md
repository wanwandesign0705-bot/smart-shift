# 申請と承認・社内連絡（作業6）

## できること

| だれ | できること |
|---|---|
| スタッフ | 有給（全日・半日）と希望休を申請する。自分の申請の状態（承認待ち・承認済み・却下と店長のひとこと）を見る。承認待ちの申請を取り消す |
| スタッフ | シフト交代を募集する。ほかの人の募集を引き受ける。引き受けた交代の状態を見る |
| 店長 | 申請が届く（理由も見える）。承認するとシフト表に反映される（有給は「有給」、希望休は休みに固定、交代は2人のシフトを入れ替え）。却下するときは、ひとことを添えられる |
| 店長 | 社内連絡を出す。だれか読むと「既読 n人」と出る |
| スタッフ | 社内連絡を読む。読んでいないと、タブに数が出る。開くと既読になる |

申請と社内連絡は、1分ごとと、画面に戻ってきたときに読み直します。

## だれに何が見えるか（データベースで守る）

| 情報 | 店長 | 本人 | ほかのスタッフ |
|---|---|---|---|
| 有給・希望休の申請（理由を含む） | 見える | 見える | 見えない |
| 交代の募集 | 見える | 見える | 日付・時間帯・募集した人の名前だけ（理由は見えない） |
| 交代を引き受けた人の名前 | 見える | 募集した本人には見える | 見えない |
| 社内連絡 | 出す・既読の人数 | 読める | 読める（同じお店のみ） |
| だれが既読か | 人数が見える | 自分の分だけ | 見えない |

スタッフは申請の表から自分の申請しか読めません。交代の募集は、`swap_board` 関数が上の項目だけを返します（`supabase/migrations/004_requests_board.sql`）。
