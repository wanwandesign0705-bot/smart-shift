# tests/

## schema.sql のテスト

`supabase/schema.sql` を空のデータベースに流し、設計書の「確かめたこと」とデータの守りを66項目確かめます。

- 店舗の作成には規約への同意が必要。匿名ログインの人は店を作れない
- トライアル中はプロになる。トライアル終了日・有料期間の終わりを過ぎると、何もしなくてもフリーになる
- 店長は契約を変えられない。運営者が変えると、変更の前後が履歴に1件残る
- フリーで6人目のスタッフを登録すると止まる
- スタッフから時給・契約・予算・未公開のシフト・他人の有給付与は見えない
- スタッフは申請を出せるが、自分で「承認」にはできない
- 招待リンクは1回だけ使え、DB にはトークンのハッシュだけが残る
- 他店のデータは、店長からもスタッフからも見えない

### 動かし方（開発者向け）

PostgreSQL 16 が必要です。テスト用に `smartshift_test` というデータベースを作り直すので、**本番の Supabase には向けないでください**。

```bash
PGHOST=localhost PGUSER=postgres bash tests/run-schema-test.sh
```

最後に「すべてのテストに合格しました」と出れば合格です。1つでも失敗すると、その場で `FAIL:` と理由を出して止まります。

`supabase-shim.sql` は、素の PostgreSQL で Supabase のログインの仕組み（`auth.uid()` など）を真似するテスト専用のファイルです。Supabase には流しません。
